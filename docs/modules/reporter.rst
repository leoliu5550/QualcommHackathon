Report Generator
================

The reporter module creates comprehensive documentation of the organization process,
ensuring transparency and providing valuable insights.

Generated Reports
-----------------

HTML Tree Visualization
~~~~~~~~~~~~~~~~~~~~~~

Interactive folder structure with:

- Expandable/collapsible folders
- File count indicators
- Visual hierarchy representation
- Print-friendly formatting

Markdown Summary
~~~~~~~~~~~~~~~

Detailed organization report including:

- File categorization statistics
- Processing time metrics
- Category descriptions and rationale
- File movement log

JSON Backup
~~~~~~~~~~~

Machine-readable backup containing:

- Original and new file paths
- Folder mapping structure
- Metadata and timestamps
- Recovery information

Features
--------

- **Transparency**: Clear documentation of all changes
- **Interactivity**: Browsable HTML reports
- **Portability**: Multiple output formats
- **Automation**: Generated without user intervention
